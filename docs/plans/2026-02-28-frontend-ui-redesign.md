# 前台 UI 重設計 — 語音置中佈局

**日期**：2026-02-28
**狀態**：設計確認，待實作

---

## 背景

現有前台採用左右 50/50 分割：左側菜單展示、右側語音+購物車。此設計對客人自助操作不直覺——客人不需要看菜單，只需要對著系統說話並確認點了什麼。

**目標**：移除左側菜單，語音操作置中，讓客人聚焦在「說話 → 確認」的流程。

---

## 使用情境

- **使用者**：客人（自助操作，站在櫃台前）
- **裝置**：平板（直向為主，橫向相容）
- **互動時長**：30–90 秒完成一次點餐

## 動畫規格

### 波形縮入 Header

- **觸發**：第一個品項加入購物車
- **動畫**：
  - 波形從畫面中央，縮小並移動到 Header 左側（店名左邊）
  - Duration：`400ms`，Easing：`ease-in-out`
  - 縮小比例：原尺寸 → 約 32px 高
- **技術**：Framer Motion `layout` + `AnimatePresence`

### AI 回覆淡出

- **觸發**：TTS 播放完畢
- **顯示**：AI 最後一句文字，淡色（`#8a9a9f`），字型小
- **淡出**：3 秒後 `opacity: 0`，duration `600ms`
- **處理中狀態**：顯示「處理中…」帶 pulse 動畫

### 波形重置

- **觸發**：`resetSession()` 呼叫後（結帳完成）
- **動畫**：波形從 Header 左側移回畫面中央並放大
- Duration：`400ms`，與縮入動畫對稱
